# Apple Neural Engine knowledge base

This directory separates public facts, source-derived observations, and unresolved questions about the Apple Neural Engine (ANE). Every technical section states its evidence level:

- **High:** an Apple primary source, source code at a fixed revision, or a repeatable repository test supports the claim.
- **Medium:** independent reverse engineering or a project receipt supports the claim, but Apple has not published the contract.
- **Low:** one observation or an indirect source supports the claim.
- **Open question:** the available evidence does not support a firm answer.

The labels measure evidence, not importance. Private interfaces and binary formats can change between operating-system and chip releases.

## Scope

This knowledge base documents the source-native compiler in this repository and the external work needed to understand its boundary. It does not describe Apple-generated bytes as a stable public ABI. The repository policy is to retain decoded fields, field tables, and hashes, not Apple-generated HWX containers or task rows. **Evidence: high.** See the repository [disclaimer](../../DISCLAIMER.md) and [H13 field ledger](../../research/h13-hwx-fields.md).

Public Core ML is the supported application interface. Direct compilation and execution use private frameworks, undocumented driver interfaces, or research drivers. Software that depends on those layers must expect release-specific behavior. **Evidence: high for the public API boundary; medium for the reconstructed private stack.** See [Core ML](https://developer.apple.com/documentation/coreml), the historical [tinygrad stack trace](https://github.com/tinygrad/tinygrad/blob/1dcaecacc476ca6369b427961c578dddf2eb9f35/ane/README), and [Hollance's runtime notes](https://github.com/hollance/neural-engine/blob/d0bb5305a595a59142df47a4581e8b0b765a7385/docs/is-model-using-ane.md).
