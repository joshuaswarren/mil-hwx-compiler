Method

Both paths used the same input and output IOSurfaces, QoS 21, deterministic
FP16 inputs, and synchronous evaluation. Each independent run used 20 warmup
evaluations followed by five alternating batches of 2,000 evaluations for
each compiler. The primary latency for a run is the median of the five batch
medians. CPU-reference correctness gates ran before each A/B.

Unavailable Apple baseline

The exact four-stage affine scan has nine external inputs. ANECompiler
returned InvalidMILProgram on both runs, so no latency ratio is reported.

Scope

The research FA2 bundle dispatches eight HWX artifacts per graph evaluation.
The research matmul-GELU bundle dispatches two. The Apple path evaluates each
whole MIL graph through one in-memory model. These numbers include the current
runtime dispatch paths. They are whole-graph latency measurements rather than
isolated HWX instruction timing.
